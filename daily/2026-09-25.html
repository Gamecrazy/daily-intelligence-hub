Google Cloud API Gateway：现有 REST 一键变远程 MCP 工具（Public Preview）

Google Developers Blog Sep 24：Cloud API Gateway 以 Public Preview 充当远程 MCP server——在已部署的 OpenAPI 3.x 规格上标注 x-google-api-management.mcp，即可把既有 REST 操作暴露为 agent 可发现/可调用的 MCP tools，无需另建托管 MCP 服务。认证、配额、日志与 REST 共用一条策略路径；文档见 cloud.google.com/api-gateway/docs/mcp-overview。

产品/事项
Google Cloud API Gateway → 远程 MCP server（Public Preview）
落款
developers.googleblog.com · SEPT. 24, 2026；配套 docs mcp-overview
怎么用
OpenAPI 3.0.x/3.1.x 文档级 mcp:true + 操作级 x-google-mcp-tool；部署后 /mcp 端点；tools/list 默认可匿名（生产可加 JWT）；tools/call 走原 REST 鉴权
客户端
任意 MCP client；示例用 ADK McpToolset + StreamableHTTPConnectionParams
边界/路线图
Preview：REST/OpenAPI3；暂不支持 resources/prompts、流式、Model Armor；同 config 不可同时开 MCP 与 Model Routing；单网关至多 ~1000 tools
是否新旗舰
否
是否推荐条
是（MCP 平台能力上架，达推荐门槛）
  • 定位：企业大量能力已在 REST 网关后；此前要单独搭 MCP 服务器重做路由/鉴权/配额。Gateway 关闭该缺口。
  • 生态位：轻量 on-ramp（Cloud Run 等）；完整企业 API/MCP 平台仍指向 Apigee；出站治理用 Agent Gateway。
  • 可发现性：接入 API hub 后 MCP 元数据可进 Agent Registry。
  • 触发 new_mcp_skill_rec=true；非产品版本列车里的附带 MCP 改动。
