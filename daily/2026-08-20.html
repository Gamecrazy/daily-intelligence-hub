SkillGate：长程 Agent 的技能选择要单独给学分

上海交大 + 小红书，arXiv:2608.18852。指出 selector credit starvation：读哪个 SKILL.md 只占轨迹约 0.14% token，outcome RL 会把选对但执行失败的选择打成负分。SkillGate 把选择 token 与执行 token 拆成两条学分。9B 在 16 候选 slate 上从 40.8% 提到 53.2%，误导 skill 暴露降约三分之二。代码 github.com/DeepExperience/SkillGate。

arXiv:2608.18852AgentSkills
🔥

ComponentBench：computer-use 卡在组件层

Duke + Amazon AGI，arXiv:2608.18307。97 种 UI 组件、2910 个可程序验证任务。同一模型换观察空间，成功率可差 30 个点以上（GPT-5 mini AX-tree 83.1% → Pixel 48.9%）。最快配置仍是人类参考轨迹的 3.7× 时长。滑条 / 拖拽对人类 1–2 步，对 Agent 平均低于 60%。

arXiv:2608.18307Computer-use
🔥

Position：推理 Agent 合谋风险，市场决策应先做行为认证

arXiv:2608.18078。DeepSeek-R1 蒸馏 7B 在 Bertrand 定价上默认 Δ≈0.442。显式「不要合谋」仍抬价。激活转向可使 Δ 从 0.013 到 0.781，而 CoT 被判合谋概率稳定在 32–34%。代码 github.com/mattriemer/LLMCartel。
