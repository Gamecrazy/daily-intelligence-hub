MaxEnt 能量加权球面矩光照编码｜arXiv:2608.20429

西工大。公告 Mon 24 Aug（Submitted 20 Aug 2026）。I4/N4/C5/R5。把路径样本写成能量加权方向特征，用总能量 + 一阶方向矩 + 无迹二阶矩（1+3+5）做线性可加、旋转协变编码；Lebesgue 参考测度下 MaxEnt 闭包给出方向概率 ∝ g−3、角能量密度 ∝ g−4，并保证可归一化时严格非负辐照度。纯偶极四参数子族给出解析余弦响应与零拒绝逆采样；同轴五参数子族用离线 LUT + 单次三线性采样做漫反射重建。

981 张 Poly Haven HDRI：MaxEnt-5 对 stored QZH 场景胜率 78.7%、平均亮度 RMSE −15.8%，高方向性桶（ρ≥0.6，392 景）胜率 91.3% 且中位误差低于全 9-DOF SH-2；MaxEnt 全场景负辐照度为 0，SH/QZH 在 52–579 景出现负值。RTX 4060 Laptop 解码微基准：32³ R16F LUT 相对 QZH 开销接近，端到端收益保留率中位 0.9997。

局限：闭包只到 l≤2；同轴子族对隧道/多源非同轴室内系统误差高；实验是静态环境光 + Lambert，非完整帧管线。面向实时紧凑光照表示，非引擎发版。

CubicSplat：误差有界前向松弛的可微矢量图形｜arXiv:2608.20803

中科大认知智能国重。公告 Mon 24 Aug（Submitted 21 Aug 2026）。I3/N4/C5/R3。把可微矢量光栅的「前向保真 vs 梯度质量」命名为 gradient seesaw：精确 Bézier 最近点求解会病态，过粗前向又优化错目标。用均匀折线代理 ΠS 把距离查询变成闭式点到线段，几何误差 O(S−2)，计算图静态；Porter–Duff 合成的可见性统计做 Gini 剪枝。

DIV2K 200 张、N=1024：闭填充 25.78 dB / 开描边 25.93 dB，相对 Bézier Splatting +2.33 / +0.48 dB，训练约 4×（闭）/ 1.8×（开）更快；256 条曲线已达 DiffVG 1024 条的 PSNR。单步 2040×1344 / 2048 曲线相对 DiffVG 约 120×。论文自称代码 github.com/CubicSplat/repo（仓库可达性未核，不单列信源）。

偏图像矢量化 / 可微 2D 渲染研究，非游戏引擎运行时；UI/2D 风格化管线可借鉴。开描边 LPIPS 有时不如点采样 splatting。

MultiCube：部件语义 + 空间双可控 3D 生成｜arXiv:2608.20448

Roblox + CMU + Stanford（Maneesh Agrawala）。公告 Mon 24 Aug（Submitted 20 Aug 2026）。I4/N4/C5/R4。在 CubePart/VecSet 上做部件语义+空间双可控：输入全局文本、部件 schema、每部件 AABB，两阶段扩散先生成对齐 layout 的整体网格，再交叉注意力同时分解部件；Stage 1 用 Part Layout Adapter 独立编码每部件（Qwen-VL + Fourier box + Q-Former），避免部件条件纠缠。

PartObjaverse-Tiny 部件级 CD 0.040 / F-score 0.948 / Box IoU 0.847，超过 CubePart / FullPart / PartPacker；端到端 Box IoU 0.717 接近带 GT 渲染的 FullPart（0.723），语义/几何 VLM 胜率 82.9% / 89.0%。应用：LLM 自动 layout、场景级推广、部件定制、刚体关节。

失败：严重错 box 会畸变；偶发部件碰撞；不支持局部迭代改一零件。面向游戏/动画组合资产，非运行时 NPC/PCG 发版。
