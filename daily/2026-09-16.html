Google DeepMind 于 Sep 15 推出 Gemini 3.8 Live 与 3.8 Live Extended Thinking：面向近实时语音对话与语音智能体的专用档，开发者经 Live API 可用；Extended Thinking 可边说边做后台多步推理。定位实时语音/Live，不当今日一般文本旗舰（现役文本旗舰仍为 Gemini 3.8 Flash）。

  • 官方称「most advanced live dialogue models yet」；Extended Thinking 在 Artificial Analysis Speech-to-Speech Quality Index 报 82.6（#1，厂商引用）、τ-Voice 68.6%、Big Bench Audio 97.7%（厂商自报，缺独立复核写未核）。
  • 能力要点：后台异步 tool/API 调用同时继续流式语音；近实时视觉上下文；97+ 语言中途切换；Extended Thinking 可配置后台推理并口头播报进度。
  • 模型卡：基于 Gemini 3 Pro；输入音频/图/视频/文本至约 128K；输出音频+文本至约 64K；知识截止写 January 2025。
  • 同日开发者文同步推 Live API 集成伙伴（Agora / LiveKit / Pipecat / Vercel 等），并提及「live api skill」；记本条附属，不另开独立 MCP 推荐条。
